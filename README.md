# 🚗 Used Car Price Estimator

## 🚀 Project Overview
How can a dealership automatically price cars fairly based on market value and condition? This project builds a complete machine learning pipeline to estimate used car prices, moving from raw data inspection to advanced predictive modeling.

## 🛠️ Skills & Tools Used
* **Languages:** Python (Pandas, NumPy, Matplotlib, Seaborn)
* **Machine Learning:** Scikit-Learn (Linear Regression, Random Forest Regressor)
* **Techniques:** Exploratory Data Analysis (EDA), Feature Engineering, One-Hot Encoding, Handling Rare Categories

## 📈 Key Results
1. **Baseline Model:** A standard Linear Regression established our initial benchmark.
2. **Feature Engineering:** Engineered a new `Car_Age` feature and cleaned messy categorical data (grouping rare brands, encoding fuel types).
3. **Advanced Model:** Upgraded to a Random Forest Regressor, which successfully captured non-linear depreciation patterns, significantly boosting the accuracy score and reducing the dollar-amount prediction error per car!
